Choose a duration with a deadline penalty

Incremental total cost = crashing cost + max(0, completion week − deadline) × penalty per week

The original project cost is not supplied and is common to all choices. Minimize incremental total cost. Average cost per week saved is descriptive and is not the decision objective.

Run the numerical exercises in class

  1. Predict. Keep solutions hidden. Ask students to classify Projects A–D and justify their attention priorities.
  2. Calculate. Reveal CV, SV, CPI, SPI and the forecasts. Ask why EV matters more than comparing AC with PV alone.
  3. Map the network. Identify all four paths and calculate the baseline completion time.
  4. Try crashing. Enter a plan, then test the 9-, 8-, and 7-week slide plans. Which shared activity benefits more than one path?
  5. Challenge the plan. Compare the lecture plans with the exact minimum-cost plans. Ask why a locally cheap crash choice can produce a costly overall plan.
  6. Add the penalty. Start with week 8 and $10,000 per late week, then change the penalty. Discuss cost ties and other reasons to prefer on-time completion.

Interpretation assumptions

Earned-value forecasts hold current performance ratios constant. Crashing assumes deterministic durations, whole-week reductions, linear crash costs and no resource constraints beyond the listed crash limits. The network structure stays fixed when you edit the data.
